This repository contains Macro Terminal, an institutional-grade 
mobile financial intelligence platform engineered with React Native
and Expo by Youness Ouani, a software developer specializing 
in modern JavaScript and TypeScript architectures.
Designed to deliver real-time macroeconomic data, global
indices, live squawk feeds, and advanced risk calculation
tools directly to mobile devices, the application features a
professional dark terminal aesthetic.
It incorporates a modular interface with seamless bottom 
tab navigation, custom animated market tickers, and a comprehensive 
grid menu housing over twenty specialized trading and analytical modules.
